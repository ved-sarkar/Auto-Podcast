# Synthetic interview fixture

Both text files in this folder were newly authored for the portfolio preparation. They describe a fictional sensor experiment, contain no real participant information, and were not taken from an interview, recording, client, employer, or confidential dataset.

`synthetic-original.txt` is the original fixture; `synthetic-edited.txt` is a deliberately authored deletion-only edit. The same strings are bundled from `src/examples/syntheticDemo.js`. This fixture demonstrates the review interface and validator, not live model performance. Its retained lowercase wording and punctuation reflect the exact-token preservation rule.
